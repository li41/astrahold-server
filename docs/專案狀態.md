## gpt-server 工作分支

gpt-server 對正式 Server 的唯一工作分支是：

**`ai-working-gpt-server`**

不得因 feature、Issue、PR、milestone、Protocol 或 integration task 建立其他 gpt-server Server 工作分支。

repository 中既有的 `gpt-server/*`、`integration/*`、歷史 feature branch 或 archive branch，只能作為歷史證據、比較來源或保留紀錄；不得再當成 gpt-server 的新工作分支。

## 正式 gameplay authority

```text
Client Intent
-> Go Server Validate / Decide
-> Authoritative State / Events
-> Client Presentation
```

Server 是唯一 gameplay truth。

## 歷史資料使用原則

舊 milestone、recovery snapshot、舊 roadmap、舊 PR 與舊 branch 可作為設計／回歸測試證據，但不能覆寫：

1. 使用者最新明確指示；
2. Project Instructions；
3. 正式 Server source / current contract；
4. 正式 repository 現行文件；
5. current PR / Issue。

若歷史文件仍描述已失效的 branch、Protocol、PR 狀態、SHA、blocker 或待辦，gpt-server 可直接整理成歷史敘述或更新為目前狀態，不保留會誤導後續施工的過時資訊。
