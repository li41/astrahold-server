## 核心設計切換：無職業制（Classless）

已確認新的正式遊戲方向：

- 不再以固定職業決定裝備／技能合法性。
- 所有正式技能最終皆可學習。
- 所有裝備原則上皆可使用，只保留真正的裝備類型、欄位、手持衝突與動作需求。
- 角色配裝流派（Build）由屬性配點、裝備、已學技能與實戰配置形成。
- 不再新增新的職業限定遊戲內容。
- 現有 v27 `ClassID`、職業限定動作與職業資源是 **舊制遷移技術債**，不是未來設計；在通訊協定、持久化與迴歸驗證安全遷移前不直接刪除正式路徑。

無職業技能組第一版已定為 20 技能：4 通用、4 近戰、4 遠攻、4 法術、4 輔助。

實戰規則：

```text
基本攻擊（basic-attack）
+ 全部 4 個通用技能
+ 全部 4 個輔助技能
+ 6 格自由戰鬥技能（從近戰／遠攻／法術 12 招選）
```

已定數值只有：體魄強健力量 +5、通暢氣脈敏捷 +5、加速術 ×1.3；靈力凝聚確定增加魔法攻擊但數值未定。其他技能數值、冷卻、距離、成長係數與學習方式仍需正式內容決策。

這次設計切換目前**不改 Protocol v27**。

## 無職業制伺服器施工狀態

### 20 技能目錄 — 已完成第一個領域基礎

`internal/skillcatalog` 已建立並與舊 `internal/classaction` 完全分離：

- 正式鎖定 20 個穩定技能 ID。
- 五類各 4 招。
- 近戰／遠攻／法術共 12 招可進六格自由戰鬥配置。
- 4 通用 + 4 輔助不占六格。
- 體魄強健、通暢氣脈、靈力凝聚為被動；加速術為主動輔助能力。
- 六格驗證拒絕第 7 招、未知技能、重複技能，以及把固定通用／輔助技能塞入六格。
- 混搭近戰／遠攻／法術合法。

此層只定義技能身分與配置不變條件，不包含傷害、冷卻、取得方式、Protocol 或持久化。

### 六格戰鬥技能執行期狀態 — 已完成第一個權威狀態基礎

`internal/skillloadout` 已建立：

- 以 runtime `EntityID` 擁有六格戰鬥配置。
- 只接受 `skillcatalog` 的合法戰鬥技能組合。
- 保留欄位順序。
- 輸入／輸出皆防止外部 slice 修改污染權威狀態。
- 非法 replacement 不得覆蓋上一份合法配置。
- 支援 authoritative entity lifecycle clear。
- 此 Store 明確是 world-owner mutable state，不自行加入另一套 lock／network authority。

Durable character state 使用 trusted `characteridentity.ID`，不是 runtime `EntityID`。因此六格配置若進持久化，必須由 `characterstate` schema 明確保存／恢復，不得把 runtime EntityID 當永久角色識別碼。

目前尚未把六格配置接到 Client intent、Protocol 或 persistence；這些後續分層完成。

## 開放中的整合／驗證 Issue

### #177 — BrowserWS 目標資源真實路徑驗證

Server seam／deterministic harness 已完成並驗證。仍等待 gpt-client Browser 真實路徑驗證；**不是 Server gameplay 施工 blocker**。

### #180 — 舊 production E2E 契約漂移

舊 production workflows 含 retired Client／舊 Protocol 假設。這是驗證技術債；不把它當成目前玩家可玩功能的優先 gate，也不為了變綠而關閉 security workflows。

### #182 — Emberwatch replacement-world 權威碰撞

Client 已提供並核准新的 **56 個 AABB blockers**，舊城堡與 #181 Emberwatch v1 blocker 集已 supersede。

但現行 `main-gate` 同時仍參與 Server 的攻城可破壞 Gate 契約，新的三個城門尚未有正式 gameplay mapping。Server 不會自行決定哪一個新門繼承舊攻城 Gate，也不會留下半套 invisible collision。碰撞資料可作為已核准 presentation/world evidence，但在 siege gate contract 明確前不做會破壞正式 world validation 的半套替換。

Client 場景施工速度不再阻塞其他 Server gameplay 工作。
