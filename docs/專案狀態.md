## 現行 gameplay truth

### 無職業角色

- fixed class 不再決定裝備／技能合法性。
- durable character state 不保存 `ClassID`。
- `CharacterRestore.LegacyRuntimeClassID`、`internal/classresource`、fixed-class resource lookup 已退役。
- generic action resource 由 `internal/actionresource` 擁有；production policy 由 `internal/actionpolicy` 擁有。
- legacy class wire 仍保留 compatibility contract，但不是 current gameplay truth。

### 20 技能／六格配置

- 20 個穩定 SkillID 已建立。
- authoritative learned-skill runtime state 已存在。
- 6 格 combat loadout 已存在，且非空配置必須是已學技能子集。
- learned skills／6 格 loadout 已 durable restore/save。
- 技能取得／學習 intent、忘卻／重置、六格何時可編輯仍沒有正式產品語義，Server 不自行發明。

### 六大角色屬性

正式 base stats：力量、敏捷、體質、智力、精神、魅力；中性基準皆為 10。

已進 live combat：

- effective AGI -> physical hit/evasion
- Strength -> melee production WeaponType basic-attack raw damage bonus
- AGI -> bow／crossbow／sling basic-attack raw damage bonus
- effective AGI -> eligible damage critical chance
- 裝備固定／隨機六大主屬性 -> effective primary stats

physical `basic-attack` 命中：

```text
HitChance = clamp(90% + (totalHit - totalEvasion) * 0.5 percentage points, 75%, 98%)
```

`totalHit` = attacker effective AGI hit modifier + weapon accuracy + authoritative equipment hit。

`totalEvasion` = target effective AGI evasion modifier + authoritative equipment evasion。

miss 不扣 HP，但仍 commit authoritative cooldown。

現行近戰正式武器的 physical basic-attack damage attribute 為 Strength；弓、十字弓、投石索為 Agility；法杖 V1 不自動取得物理主屬性加成。

eligible damage critical chance：base 5%；AGI 超過 30 後每完整 +10 AGI 增加 1pp，再加 `CriticalRating * 0.5pp`，上限 30%。

### 武器／裝備／unique item

- production catalog：53 把武器＋3 面低階盾牌。
- MainHand／OffHand、裝備 durable restore/save 已存在。
- basic-attack cadence ownership：`WeaponType -> BasicAttackIntervalMS`。
- 18 類 V1 cadence 已 authored；空手 600ms。
- 投石索／弓／十字弓正式 ranged basic-attack range 分別為 14m／18m／22m。
- `WeaponType` 單手／雙手 gameplay 佔用已正式化；雙手與盾牌不可並存。
- unique equipment 已有 stable `ItemInstanceID`、Server-rolled affix、exact-instance equip/unequip、durable state 與 v28 Type119–121。
- 低階 0 詞綴、中階 1 詞綴、高階 2 條不同詞綴。
- 通用 `static_modifiers` 已存在；目前正式 weapon content 只使用法杖固定魔法威力低 +1／中 +2／高 +4。
- 掉率、商店、價格、任務、製作與經濟來源仍未定案；Server 不自行補完。

### 皮膚 WeaponType affinity +1

- gameplay identity 使用 Server-owned `SkinID`。
- selected skin 與 authoritative main-hand WeaponType 相符時，目前 formal scope 的 `basic-attack` raw physical damage flat +1。
- 加值位置：weapon roll -> primary-stat bonus -> skin +1 -> equipment flat physical -> critical -> defense/block/self mitigation。
- Client 透過 Type122 `AppearanceSnapshot.basic_attack_affinity_bonus` 讀 Server 算好的 0/1，不自行重算。
- Server 不保存 Mixamo UUID／GLB path／Client asset path。

### 遭遇／掉落／生命週期

- damage-driven threat V1 已存在。
- invalid target／despawn／defeat／leave／respawn／leash 有清理路徑。
- ground drop 有 authoritative bounded TTL。
- pickup／autopickup／expiry／rollback 共用 authoritative lifecycle。
- defeated character 不得 pickup／equip／unequip。
- generic transient-status lifecycle foundation 已存在。

## 地圖／場景狀態與工作邊界

依目前正式方向：**地圖由 Client 主導，Server 不先規劃。**

- map／scene layout、視覺動線、場景資產與 playable-space 由正式 Three.js Client 推進。
- Server 不主動排下一張地圖、新手村重做、castle／wall／portal／siege gate、blocker 數量或 spawn layout。
- Client 完成具體 playable slice 並需要 gameplay authority 時，再透過 Issue／comment handoff。
- Server 屆時只實作必要 authoritative collision／traversability／teleport／spawn／region／AI／siege legality。
- Client raycast／scene collider／node／asset path 不會自動成為 gameplay truth。

現有 `worlds/castle-sandbox/gameplay.json` 與 Emberwatch blockers 只視為現行既有 Server config／歷史相容事實，不代表未來地圖 roadmap。
