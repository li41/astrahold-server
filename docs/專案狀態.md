## 核心設計切換：Classless

已確認新的正式 gameplay 方向：

- 不再以固定職業決定裝備／技能合法性。
- 所有正式技能最終皆可學習。
- 所有裝備原則上皆可使用，只保留真正的 equipment / slot / hand requirements。
- 角色 Build 由屬性配點、裝備、已學技能與實戰配置形成。
- 不再新增新的 class-gated gameplay。
- 現有 v27 `ClassID`、class-gated actions、class resources 是 **legacy migration debt**，不是未來設計；在 Protocol / persistence / regression 安全遷移前不直接刪 production path。

Classless Skill Set V1 已定為 20 技能：4 通用、4 近戰、4 遠攻、4 法術、4 輔助。

實戰規則：

```text
basic-attack
+ 全部 4 通用
+ 全部 4 輔助
+ 6 格自由戰鬥技能（從近戰／遠攻／法術 12 招選）
```

已定數值只有：體魄強健力量 +5、通暢氣脈敏捷 +5、加速術 x1.3；靈力凝聚確定增加魔法攻擊但數值未定。其他技能數值／CD／range／scaling／學習方式仍需正式內容決策。

這次設計文件本身**不改 Protocol v27**。

## Current gameplay truth that docs must preserve

### Low-tier weapon accuracy

現行 Server 已啟用，不再是「資料存在但未生效」：

```text
HitChance = clamp(90 + accuracy_modifier * 2, 75, 98)
```

只套 authored low-tier weapon 的 entity-target `basic-attack`；Server owns roll。Miss 不扣 HP、會產生 authoritative miss outcome、cooldown 仍成立。

### Equipment

已有 5 把低階武器、3 面盾牌、MainHand / OffHand、weapon damage / attack interval / accuracy、shield mitigation / block / magic reduction、equipment persistence。

這 8 件低階裝備仍沒有正式 acquisition / drop rate / shop / quest / crafting / starting equipment / price。

### Encounter / lifecycle

- actual-damage-driven threat v1 已完成。
- evade / defeat / despawn / respawn 清 encounter truth。
- evade 亦清與該 monster 相關的 transient source-target combat resource。
- generic transient status foundation 已存在。
- public ground drop 有 authoritative bounded expiry。
- defeated actor 不得 pickup / equip / unequip。
