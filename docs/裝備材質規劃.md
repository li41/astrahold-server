# 星壘 — 裝備材質規劃

本文件定義現行正式 Server equipment catalog 的**主材質**規劃，以及第一版材質 gameplay 規則。

Server 是唯一 gameplay authority。材質屬於 `ItemArchetypeID` 的穩定 gameplay metadata；Client 的貼圖、PBR、shader、mesh material 名稱與 asset path 不得決定 gameplay outcome。

本契約已在 `facdfd5d292eb9cc05b1c13bcedf02ed2918a820` 落地：`Definition.Material` 已收斂為 typed `MaterialID`，production 107 件 equipment 以 exact `ItemArchetypeID` 映射主材質，並接入 Server-owned `undead` 與銀質主手武器 V1 普攻規則。Server CI #1290 已實際通過 `go test ./...`、`go vet ./...` 與 configured race detector。

## 一、主材質原則

每個裝備 archetype 只有一個 gameplay 主材質。

- 劍、匕首、斧、矛、鎚、拳套、爪、雙刀：看主要攻擊部件。
- 弓：看弓身。
- 弩：看主要弓臂／機構。
- 法杖：看杖身。
- 盾牌：看主要承力／防護結構。
- 防具：看主要防護層。

木柄、皮纏、鏈條等次要構造未來可進 crafting recipe，但不建立第二份 gameplay 材質 truth。

`ItemInstance` 不重新骰材質；unique instance 一律繼承 `ItemArchetypeID` 的主材質。

## 六、銀對不死 V1

只在以下條件全部成立時啟用：

1. 攻擊來源是玩家目前權威裝備的 `main_hand`。
2. 主手 `ItemArchetypeID` 的主材質為 `silver`。
3. 本次傷害是正式 `basic-attack` 的武器物理傷害。
4. 目標具有 Server-owned 穩定不死系分類 `undead`。

正式效果：

```text
銀對不死加成後原始物理傷害 = floor(原始物理傷害 × 1.20)
```

計算順序：

```text
武器／角色／裝備對本次 basic-attack 的 raw physical damage 聚合
-> 若 silver + undead，×1.20 並向下取整
-> critical
-> 目標 physical mitigation
-> block
-> 最終 authoritative damage
```

V1 不作用於：

- spell damage
- DoT
- poison／bleed／burn 等 status tick
- thorns／reflect
- summon damage
- shield damage
- armor
- off-hand 銀材質

銀加成不因身上多件銀裝疊加；只看實際造成該次普攻的主手武器。

## 七、不死系分類

`undead` 是 Server-owned stable gameplay identity，保存在 authoritative `world.EntityState` gameplay metadata；不得從 presentation 推導。

不得以顯示名稱、Client asset path、mesh 名稱、animation、VFX 或 UI tag 推導不死系。

目前尚未指定哪些正式怪物屬於 `undead`；等怪物內容表定案時逐 archetype／spawn authority 指定，不從名稱自行猜測。

## 八、其他材質目前沒有隱性倍率

V1 明確不替其他材質增加額外能力：鐵、鋼、星鋼、木、強化木、秘紋木、星木、皮革、強化皮革、星影皮革、布、秘紋布、星輝織物都沒有額外攻擊、防禦、移速、魔法或抗性倍率。

裝備實際強度仍由 archetype 自身的傷害、防禦、重量、static modifier、requirement、affix 與 set bonus 決定。

材質目前只作為：

- 穩定裝備分類
- 未來 crafting recipe hook
- 未來 repair／salvage／economy hook
- 少量明確 gameplay interaction 的依據

不建立全域「材質倍率表」。

## 九、已落地 Server contract

1. `Definition.Material` 已使用 stable `MaterialID`；gameplay 不用字串 contains 判斷材質。
2. catalog validation 拒絕未知／歷史複合材質 ID。
3. 現行 107 件 production equipment 全部有且只有一個正式主材質，以 exact `ItemArchetypeID` 映射保護。
4. unique `ItemInstance` 不保存第二份材質 truth；材質由 archetype resolve。
5. 已有通用 Server-owned `undead` classification；沒有為單一怪物硬寫名稱判斷。
6. 銀 V1 加成已接入 authoritative basic-attack raw-damage owner path，位於 critical／mitigation／block 之前。
7. regression 覆蓋 silver+undead、silver+non-undead、non-silver+undead、non-basic／magic 無加成、floor／saturation 與 critical 順序；既有完整 Server CI 同時保護 shield／spell／status 等 owner paths。
8. 本 slice 沒有新增 wire field，因此 Protocol 維持 v29；Client 若要顯示材質／不死加成 tooltip，再另做 presentation handoff。

## 十、尚未定案

目前不決定：

- durability／repair cost
- crafting recipe
- salvage quantity
- 商店價格／掉落來源
- 材質稀有度
- 銀以外材質特殊效果
- 星鋼／星木／星影皮革／星輝織物額外能力
- 銀對玩家、野獸、惡魔、元素等非不死分類效果
- weapon skill 是否未來繼承銀 bonus
