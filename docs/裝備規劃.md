# 星壘 — 裝備規劃

本文件記錄正式 Server 的裝備內容規劃。Server 是唯一 gameplay authority；Client 只消費權威裝備狀態與事件，不得自行決定裝備合法性、傷害、屬性需求、套裝效果、攻速、命中、格擋、擊暈、箭矢消耗或其他 gameplay 結果。

本文件中的 `ItemArchetypeID`、裝備欄位、需求、基礎數值與套裝效果，均作為正式 Server 規劃依據；Client 模型、動畫、圖示與資產路徑不屬於 gameplay identity。若本文件的未來內容提案與 current Server source 不一致，以 current Server source／contract 為正式 gameplay truth。

## 一、裝備總量與階級

**目前 production catalog 為 107 件可裝備 equipment archetype：53 武器＋9 盾牌＋45 防具。**

箭矢是另外的可堆疊背包消耗品，不計入上述 107 件，也不新增第八個裝備欄位。正式箭矢規則見 [箭矢規劃](箭矢規劃.md)。

下表的 105 件是「投石索三階線正式收斂成單一趣味武器石頭」後的可裝備內容目標，不得拿來覆寫目前 production 107 件的事實：

| 類別 | 未來目標數量 |
|---|---:|
| 16 種進階武器 × 低／中／高 | 48 |
| 趣味武器「石頭」 | 1 |
| 現有額外低階單手劍 | 2 |
| 3 條盾牌 × 低／中／高 | 9 |
| 低階散裝防具 | 15 |
| 中階三套套裝 | 15 |
| 高階三套套裝 | 15 |
| **總計** | **105** |

在「石頭」正式取代 current `sling` 三階 production line 前，current catalog 保持 107；不得只為符合 105 的規劃數字而刪除現行 stable item identity。

階級規則：

| 階級 | 基礎屬性需求 | 隨機詞綴 |
|---|---|---:|
| 低階 | 無 | 0 |
| 中階 | 無 | 1 |
| 高階 | 有 | 2 |

高階裝備的屬性需求只看角色自身的永久基礎屬性，不計裝備加成、套裝效果、Buff 或其他臨時狀態。裝備自身提供的屬性不得反過來滿足自身穿戴需求。live equip 與 durable restore 都必須由 Server 重新驗證。

「石頭」不屬於低／中／高階進程，不產生中高階版本，也不參與階級詞綴成長；此項仍是後續 weapon identity cleanup，不能當成已完成 production source。

### 弓箭彈藥正式規則

弓本體只提供一部分攻擊力，箭矢本身也提供攻擊力。正式完整規則見 [箭矢規劃](箭矢規劃.md)。

第一版固定：

- 每次真正成立的弓普通攻擊消耗 1 支箭。
- 射出去但未命中仍消耗 1 支箭。
- 沒有箭時 Server 拒絕射擊，不產生權威射擊結果、不產生傷害，也不啟動該次攻擊冷卻；Client 可以只播放本地拉弓／放箭動畫。
- 目標非法、超出射程、冷卻中等未成立攻擊不消耗箭。
- 箭是背包可堆疊消耗品，不是裝備欄位。
- 第一版只有 `bow` 使用箭；`crossbow` 不共用箭。
- 第一版箭矢不計負重，但仍佔一個背包 stack。
- 多種箭共存時，Server 固定優先使用木箭，再使用鋼箭，最後使用星鋼箭。

三種正式箭矢：

| 階級 | ID | 名稱 | 材質 | 箭矢傷害 |
|---|---|---|---|---:|
| 低階 | `item_low_arrow` | 木箭 | 木 | 6–8 |
| 中階 | `item_mid_arrow` | 鋼箭 | 鋼 | 8–11 |
| 高階 | `item_high_arrow` | 星鋼箭 | 星鋼 | 10–15 |

弓箭的基礎武器傷害區間由 Server 以「弓本體傷害＋實際使用的箭矢傷害」合成，再在合成後的完整區間內只擲一次隨機值。不得分別擲弓與箭後再相加。

同階配對維持原有總傷害進程：

| 階級 | 弓本體 | 同階箭 | 合計 |
|---|---:|---:|---:|
| 低階 | 2–3 | 6–8 | 8–11 |
| 中階 | 3–4 | 8–11 | 11–15 |
| 高階 | 4–5 | 10–15 | 14–20 |

第一版沒有銀箭；現行「銀質主手武器對不死系 +20%」只適用於正式主手銀武器，不因箭的材質自動觸發。

### 石頭正式方向

「石頭」不是投石索，也不是另一種弓類武器。角色就是直接拿石頭丟出去，主要目的是增加遊戲趣味與世界互動感。

正式規劃規則：

- 只存在一種「石頭」，不分小／中／大，也不分低／中／高階。
- 建議穩定 ID：`item_throwing_stone`。
- 基礎攻擊間隔固定 1100ms。
- 普攻傷害看力量，不看敏捷。
- 基礎數值：小型傷害 5–8、大型傷害 5–8、額外傷害 0、命中修正 +1、重量 1。
- 不產生階級隨機詞綴；定位不是高階主力遠程武器。
- 實際命中後，由 Server 擲一次擊暈判定：**10% 機率造成 0.75 秒擊暈**。
- 未命中不擲擊暈。
- Boss 與特殊怪物對石頭的擊暈效果**完全免疫**；石頭命中時仍正常結算命中與傷害，只是不套用擊暈。
- 一般怪物與菁英怪物可正常進入 10% 擊暈判定。
- PvP 對玩家的擊暈規則另行定案，不因 PvE 規則自動沿用。
- 擊暈的套用、持續時間與免疫判定全部由 Server 權威路徑決定，Client 只呈現結果。
- Server 現行舊識別若仍使用 `sling`，後續實作應以獨立 migration／contract 收斂為不帶「投石索」語義的正式投石識別；不能靜默更名已持久化 identity。

石頭擊暈應接入通用狀態／控制效果機制，不得在單件物品邏輯中硬寫第二套擊暈系統。Boss／特殊怪物免疫也應由 Server 的目標原型／控制免疫政策表達，而不是由 Client 或資產名稱推導。

### 「晨星」名稱修正

原先 `morning_star` 的中文「晨星」辨識度太低，不作為正式玩家顯示名稱。

第一版依實際美術外型採下列其中一種：

- 若是柄、鏈條、帶刺鐵球：正式中文名稱使用「鏈錘」。
- 若是固定柄直接連接帶刺頭部：正式中文名稱使用「狼牙錘」。

在美術外型最終確認前，Server 穩定識別仍可維持既有 `WeaponType`，但文件與玩家顯示不得把「晨星」當作已定案的正式中文名稱。

若最終採鏈錘方向，三階名稱暫定：

- 低階：鐵鏈錘
- 中階：精鋼鏈錘
- 高階：星刺鏈錘

## 五、防具欄位

正式防具使用五個核心欄位：

- 頭部 `helmet`
- 胸部 `chest`
- 手部 `gloves`
- 腿部 `legs`
- 足部 `boots`

防具方向是配裝流派，不是職業限制。任何角色都可依 Server 裝備需求自由混穿。

## 十、套裝權威規則

套裝效果由 Server 根據當前實際穿戴的 `ItemArchetypeID`／`SetID` 即時計算。

不得持久化第二份可變的「套裝效果已啟用」真相。登入、換裝、卸裝、死亡／重生需要重建有效裝備狀態時，都從實際裝備重新計算。

正式 armor set 只使用：

- 2 件效果
- 5 件效果

不建立 3 件或 4 件效果，以保留無職業混裝與混合流派空間。
