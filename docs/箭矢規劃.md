# 星壘 — 箭矢規劃

本文件定義正式 Server 的弓箭彈藥規則。Server 是唯一 gameplay authority；Client 可以播放拉弓、放箭動畫與顯示箭矢數量，但不得自行決定是否真的射出箭、消耗幾支箭、命中、傷害或冷卻。

> 2026-09-17 產品規格更正：正式箭矢只有 **木箭、銀箭**。先前文件／Client handoff 中的鋼箭、星鋼箭三階方案已 supersede，不再是正式 gameplay truth。

## 一、核心規則

第一版固定：

- 弓的普通攻擊需要箭。
- 每次真正成立的射擊消耗 **1 支箭**。
- 射出去但未命中，仍消耗 **1 支箭**。
- 沒有箭時，Server 拒絕射擊：不產生權威射擊事件、不產生傷害、不產生權威投射物，也不啟動該次攻擊冷卻。
- 沒有箭時，Client 仍可播放本地拉弓／放箭動畫作為操作回饋，但不得自行生成 gameplay 結果。
- 目標非法、超出射程、冷卻中等未成立的攻擊不消耗箭。
- 箭是背包中的可堆疊消耗品，不是裝備欄位。
- 第一版只有 `bow` 使用箭；`crossbow` 不共用箭，未來若需要彈藥則另規劃弩矢。
- 投石類武器不使用箭。

## 二、正式兩種箭

| 穩定 ItemArchetypeID | 中文名稱 | 主材質 | 箭矢基礎傷害 | 單支負重 |
|---|---|---|---:|---:|
| `item_low_arrow` | 木箭 | 木 | 6–8 | 0 |
| `item_silver_arrow` | 銀箭 | 銀 | 6–8 | 0 |

`item_low_arrow` 已是既有可玩弓系使用的 stable identity，因此保留該 ID，不為了中文名稱再做沒有必要的 persistence／Client identity churn。

以下 ID **不是正式箭矢**，不得再由 Server catalog、Client UI、商店／掉落規劃或 gameplay contract 當作可用弓箭：

- `item_mid_arrow`（舊鋼箭）
- `item_high_arrow`（舊星鋼箭）
- `item_starsteel_arrow`

目前背包負重使用整數粒度；如果每支箭至少計 1 重量，少量箭就會不合理地吃滿角色負重。因此兩種箭第一版皆不計負重，但仍佔用一個背包堆疊項目。

## 三、弓本體與箭矢共同決定傷害

兩種正式箭目前都提供相同的 6–8 基礎箭矢傷害。這次產品更正只移除錯誤的鋼箭／星鋼箭進程，不藉機重新平衡既有三把 production 弓的總輸出。

普通弓箭攻擊的基礎武器傷害區間：

```text
最小傷害 = 弓最小傷害 + 箭最小傷害
最大傷害 = 弓最大傷害 + 箭最大傷害
```

Server 在合併後的完整區間內只擲 **一次** 隨機傷害，不分別擲弓與箭後再相加。

為維持既有 production 弓總傷害，弓本體的 ammunition split 為：

| 弓 | 弓本體 | 木箭／銀箭 | 合計區間 |
|---|---:|---:|---:|
| `item_hunter_shortbow` | 2–3 | 6–8 | **8–11** |
| `item_mid_bow` | 5–7 | 6–8 | **11–15** |
| `item_high_bow` | 8–12 | 6–8 | **14–20** |

因此木箭與銀箭都不會因為舊的「箭矢階級」概念改變弓的基礎 progression。

## 四、箭矢選擇

第一版不新增額外選箭介面或新的 Protocol 欄位。

玩家背包同時存在兩種箭時，Server 固定依下列順序消耗：

```text
木箭
-> 銀箭
```

也就是有木箭時先使用木箭，避免玩家沒有明確選箭機制時默默消耗銀箭。

未來若產品需要玩家主動指定箭種，再新增明確的 Server-owned 選箭狀態與 Client 消費契約；不得以 Client 本地選單直接決定實際消耗箭種。

## 五、銀箭目前不自動取得銀武器效果

現行正式規則「銀質主手武器對不死系物理 basic-attack 原始傷害 +20%」的判定來源，是角色目前 authoritative `main_hand` 的裝備主材質。

銀箭的 `MaterialSilver` **不會自動把這條主手武器規則擴張到 ammunition**。如果未來要讓銀箭對不死系有額外效果，必須另外定義明確的 Server gameplay contract、測試與傷害結算順序；Client 不得因名稱或材質自行加傷害。

## 六、一次射擊的權威流程

```text
Client 發出普通攻擊意圖
-> Server 驗證角色／目標／冷卻／射程
-> Server 確認主手是否為弓
-> Server 依木箭 -> 銀箭順序確認背包是否有可用箭
-> 沒箭：拒絕，不扣箭、不啟動這次攻擊冷卻、不產生傷害
-> 有箭：進入實際射擊
-> Server 擲命中
   -> 未命中：扣 1 支實際選中的箭，產生 miss 結果
   -> 命中：弓傷害 + 該支箭傷害，扣 1 支實際選中的箭
-> 後續屬性加成／暴擊／減傷／格擋沿用既有 Server 權威傷害流程
```

箭矢消耗必須修改正式角色背包 truth，並透過既有 inventory snapshot／持久化路徑保存；不得只在 Client 畫面扣數量。

## 七、與裝備總數的關係

箭矢是獨立的可堆疊消耗品，不計入 equipment archetype 總數，也不新增裝備欄位。

## 八、目前未定內容

以下不因本次「木箭／銀箭 only」更正自動決定：

- 怪物掉箭的掉落表與掉率。
- 商店是否販售、價格多少。
- 任務獎勵數量。
- 製作配方與材料成本。
- 銀箭是否有額外對不死系效果。
- 特殊箭／屬性箭。
- 弩矢系統。
- 玩家主動指定箭種的介面與契約。

這些內容必須在產品規則正式決定後，再接入既有 Server authority，不得由 Client 或單一資料表自行創造第二套 gameplay truth。
