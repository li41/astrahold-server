# 星壘 — 箭矢規劃

本文件定義正式 Server 的弓／十字弓彈藥規則。Server 是唯一 gameplay authority；Client 可以播放射擊動畫、顯示數量與選中箭種，但不得自行決定是否成立射擊、實際消耗哪種箭、命中、傷害或冷卻。

> 2026-09-18 產品規格：正式箭矢只有 **木箭、銀箭**；`bow` 與 `crossbow` 都需要並消耗箭。玩家未手動選箭時自動順序為 **木箭 -> 銀箭**；雙擊箭矢時 Client 送選箭 intent，由 Server 決定是否切換。

## 一、正式箭矢

| ItemArchetypeID | 中文名稱 | 材質 | 箭矢傷害 | 單支負重 |
|---|---|---|---:|---:|
| `item_low_arrow` | 木箭 | wood | 6–8 | 0 |
| `item_silver_arrow` | 銀箭 | silver | 6–8 | 0 |

以下 ID 已 supersede，不是正式可用箭矢：

- `item_mid_arrow`
- `item_high_arrow`
- `item_starsteel_arrow`

箭矢是 durable inventory stack，不是裝備欄位。V1 仍為零負重。

## 二、弓與十字弓都需要箭

- `bow` 與 `crossbow` 的 physical `basic-attack` 每次真正成立都消耗 **1 支箭**。
- miss 仍消耗 1 支。
- 沒有木箭或銀箭時，Server 拒絕射擊，不產生 CombatEvent／傷害，也不提交該次攻擊 cooldown。
- invalid target、out of range、cooldown 中等未成立攻擊不消耗箭。
- Client 不 optimistic 扣箭；`InventorySnapshot` 是數量 truth。
- sling 等其他武器不使用這套箭。

## 三、傷害規則

### Bow

Bow 仍採「弓本體 + 實際箭矢」一次 combined roll：

| 弓 | 弓本體 | 木／銀箭 | 合計 |
|---|---:|---:|---:|
| `item_hunter_shortbow` | 2–3 | 6–8 | 8–11 |
| `item_mid_bow` | 5–7 | 6–8 | 11–15 |
| `item_high_bow` | 8–12 | 6–8 | 14–20 |

### Crossbow

十字弓改為需要並消耗相同木箭／銀箭，但本次產品決定**沒有指定把箭矢 6–8 再加進十字弓基礎傷害**，因此 V1 保留既有 authored crossbow damage：

- `item_hunter_light_crossbow`：12–15
- `item_mid_crossbow`：17–21
- `item_high_crossbow`：22–27

也就是：crossbow 射擊 legality／箭種／消耗由 Server 處理；基礎武器傷害仍使用十字弓現行 authored range。

## 四、選箭 — Protocol v33

玩家沒有手動選箭時，Server 自動使用：

```text
木箭
-> 銀箭
```

玩家雙擊背包中的木箭或銀箭時，Client 不直接改 gameplay state，而是送 Reliable intent：

- Type 128 `ClientAmmunitionCommand`
  - `operation = "select"`
  - `item_archetype_id`
- Type 129 `AmmunitionResult`
  - `client_action_sequence`
  - `operation`
  - `outcome = selected | rejected`
  - `reason = invalid_ammunition | insufficient_inventory | defeated | server_rejected`
  - `item_archetype_id`
- Type 130 `AmmunitionState`
  - `selected_item_archetype_id`
  - 空字串代表 automatic 模式

Server 只允許玩家實際擁有的正式箭種成為手動選擇。選中箭種尚有庫存時，bow／crossbow 都優先消耗該箭；選中 stack 耗盡後 Server 自動清除 selection，回到木箭 -> 銀箭。

V1 selection 為 **session-scoped**，不提升 character schema；reconnect/relogin 回 automatic 模式。若未來要 durable 選箭，再另做明確 persistence 決策。

## 五、銀箭對 undead +20%

當 physical `basic-attack` 實際消耗 `item_silver_arrow`，且目標為 Server-owned `undead`：

```text
silver raw damage = floor(raw physical damage * 1.20)
```

規則同時適用 bow 與 crossbow。

如果 authoritative main-hand 本身也是銀材質，銀主手與銀箭加成仍只套 **一次**，不得疊成 1.44。

順序維持：

```text
weapon/ammunition raw aggregate
-> primary / skin / equipment raw modifiers
-> silver-vs-undead x1.20 once
-> critical
-> mitigation
-> block
```

Client 不由名稱、VFX、本地 inventory 或材質 mapping 推算 gameplay bonus，只呈現 Server CombatEvent。

## 六、權威流程

```text
Client basic-attack intent
-> Server 驗證角色 / 目標 / cooldown / range
-> Server 判斷 bow / crossbow 是否需要箭
-> 若有手動 selection 且該 stack > 0：使用 selected arrow
-> 否則 automatic 木箭 -> 銀箭
-> 無合法箭：reject，不扣箭、不提交 cooldown
-> 成立射擊：
   -> miss：扣 1 支實際選中的箭
   -> hit：
      bow = bow + arrow combined roll
      crossbow = existing authored crossbow damage
      扣 1 支實際選中的箭
      若 fired arrow 是 silver 且 target undead：raw x1.20 once
-> InventorySnapshot / AmmunitionState / CombatEvent authoritative replication
```

## 七、尚未定義

本次規格不自行決定：

- 掉落表／掉率
- 商店價格
- 任務獎勵
- 製作配方
- 其他特殊箭／屬性箭
- 是否未來把選箭 preference 做 durable persistence
