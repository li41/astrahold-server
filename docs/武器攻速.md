# 武器攻速

本文件記錄 Astrahold 正式 Server 的基礎普攻節奏。Server 是唯一 gameplay authority；Client 只依 authoritative state/events 呈現動畫，不得以動畫、本地計時或 asset mapping 決定攻擊是否合法、DPS 或 cooldown。

## 權威規則

- 持械普攻的基礎間隔由 `WeaponType -> BasicAttackIntervalMS` 持有。
- 同一 `WeaponType` 的所有 `ItemArchetypeID` 共用同一基礎攻速；單件武器不得覆寫。
- 空手沒有裝備 `WeaponType`，使用 `basic-attack` action definition 的 `600 ms` 基礎間隔。
- Server 在 action prepare/commit path 決定實際 cooldown；Client 以 `CombatEvent.cooldown_ready_tick` 等 authoritative event 資訊對齊呈現。
- 盾牌不產生 basic attack；釣竿是道具，不列入武器攻速。
- 未來若有裝備、Buff 或屬性攻速加成，仍由 Server 算出 effective cadence；不得要求 Client 自行套倍率決定 gameplay timing。

## 實作位置

- `internal/equipmentcatalog/default.json`：持械 `WeaponType` 正式基礎間隔。
- `config/combat-actions.json`：空手／沒有可套用持械 cadence 時的 `basic-attack` action 基礎間隔，目前正式值為 `0.6s`。
- `internal/equipmentcatalog/catalog.go`：shared WeaponType cadence loader / ownership。
- `internal/equipmentcatalog/catalog_test.go`：正式表與同類同速規則的測試保護。

## 呈現邊界

Client 的動畫實測可作為商用品質與 presentation constraint 的輸入，但不能反向成為 gameplay authority。若動畫片段短於 Server 間隔，可播完後回待機等待；若動畫需要裁切或調整播放速率，Client 可以處理呈現，但不得延後 Server 已合法的下一次攻擊。
