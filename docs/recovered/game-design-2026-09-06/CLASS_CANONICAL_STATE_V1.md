# 《星壘》六職業 Canonical State V1

## 目的

六職業經過 8 技設計、追加 2 個輔助／被動、重複性檢查與第一版數值平衡後，部分較早的單職業文件仍保留舊名稱或舊效果描述。

本文件提供目前的 **Canonical V1 快照**，避免實作時誤讀舊草案。

若文件內容衝突，第一版實作優先級：

1. `CLASS_CANONICAL_STATE_V1.md` — 目前技能名稱／核心功能快照
2. `CLASS_BALANCE_BASELINE_V1.md` — CD、資源、D/H/S、控制數值
3. `CLASS_ROLE_OVERLAP_AND_COUNTER_AUDIT.md` — 去重與互剋規則
4. `CLASS_AUXILIARY_SKILLS.md` — 第 9／10 技原始詳細說明
5. `classes/*.md` — 職業幻想、戰鬥循環、情境說明；其中舊名稱需按本文件解讀

最終進入 Server／Unreal 實作前，再把所有單職業文件逐一完全同步；現在先避免為純文件重寫阻塞玩家可見進度。

# 一、守誓者

核心：穩住戰線。

資源：決意 0～100。

1. 劍擊
2. **破勢斬** — 舊文件若寫「破甲斬」，一律以破勢斬為準；不降護甲，改為提高失衡／破勢窗口
3. 盾擊
4. 震地擊 — 高失衡 + 緩速，不主打推退
5. 堅守
6. 盾鋒突進
7. 護衛誓約
8. 不退陣線
9. 護衛挑戰
10. 盾下反擊（被動）

守誓者不再是全隊護甲降低來源。

# 二、破陣者

核心：正面撕開戰線。

資源：戰勢 0～100。

1. 重刃斬
2. 裂甲重劈 — 六職業主要的全隊護甲降低來源
3. 崩勢斬
4. 橫掃 — 保留明顯隊形打散
5. 破陣突進
6. 鋼意
7. 處決重擊
8. 破軍之勢
9. 震陣怒吼
10. 乘破追擊（被動）

---

# 三、巡獵者

核心：找出現在最該處理的目標。

資源：獵勢 0～100。

職業機制：鎖定獵物，不佔 10 技。

1. 獵弓射擊
2. 弱點箭
3. 穿甲箭 — 只讓巡獵者自己的該次攻擊忽略部分護甲，不提供全隊減甲
4. 繫足陷阱
5. 震弦箭
6. 撤步射擊
7. 鷹眼偵察 — 個人追蹤／足跡／稀有獵物資訊，不再做泛用區域反隱
8. 狩獵時刻
9. 示警信標 — 團隊小範圍反側翼／反隱匿
10. 追獵本能（被動）

# 四、星火術士

核心：決定哪一塊地現在不能站。

資源：星熱 0～100；強力施法增加星熱，不是普通 Mana 消耗。

1. 火矢
2. 星焰爆
3. 熾地
4. 星火環 — 小範圍施法者自保推離
5. 灼星鎖
6. 星步
7. 冷星引流
8. 燼雨
9. 星燼護幕
10. 餘燼回流（被動）

# 五、誓療師

核心：在隊伍要崩之前做對預判與救援。

資源：誓印 0～3；Server 可維護隱藏誓印進度。

1. 誓光擊
2. 回誓 — 友方治療／敵方懲戒
3. 護誓
4. 淨誓
5. 誓環 — 友方治療 + 敵方小範圍傷害
6. 退邪震印 — PvP 主打減速／失衡，不和星火環做相同推退
7. 續命誓約
8. 不滅誓域
9. 守望祝福
10. 誓光回響（被動）

誓療師單人普通野外擊殺速度目標仍約純輸出職的 85～90%，以續航補足差距。

# 六、影刃者

核心：從側翼／後排建立破綻，短時間製造局部優勢，再決定撤離。

核心機制：目標破綻，最多 3 層，不共享給其他影刃者。

1. 雙刃連擊
2. 裂隙刺
3. 封喉
4. 影步
5. 斷筋刃
6. 煙幕撤離
7. 破綻處決
8. 獵影時刻
9. 擾亂飛刃
10. 伺機破綻（被動）

不做永久隱身、不做滿血零反應一套秒殺。

# 七、共通數值規則

完整數值見 `CLASS_BALANCE_BASELINE_V1.md`。

目前共通骨架：

- 基本攻擊：依武器約 0.95～1.35 秒節奏
- 常用進攻：6～10 秒 CD
- 打斷／位移／控制：10～16 秒
- 防禦／重要輔助：18～30 秒
- 代表大招：約 60～75 秒
- 約 0.6 秒共享動作鎖作為原型候選，不是重型 GCD

PvP：

- 同名 Debuff 不疊強度
- 全來源護甲降低上限候選 20%
- 外部隊友減傷上限候選 30%
- 治療降低上限候選 30%
- 同類硬控 8 秒內採遞減候選

# 八、能力值連接

職業技能的屬性 Scaling Family 見 `ATTRIBUTE_SCALING_BASELINE_V1.md`。

主要方向：

- 守誓者：STR 主；WIL 保護向次要
- 破陣者：STR
- 巡獵者：DEX
- 星火術士：INT
- 誓療師：攻擊 INT；治療／護盾 WIL
- 影刃者：DEX
- CHA：跨六職業寵物／夥伴 Build，不直接免費提高本職技能傷害
