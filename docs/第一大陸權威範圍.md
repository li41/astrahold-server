# 第一大陸 Server 權威範圍

本文件記錄從正式 Client `ai-working-gpt-client` World Master Layout v1.0 同步到 Server 的地理 authority 邊界。正式可執行資料以 `worlds/castle-sandbox/gameplay.json` 為準；本文件只說明語義與來源邊界。

## Authority 分層

Server 仍是 gameplay 唯一 authority：

```text
Client Intent
-> Go Server Validate / Decide
-> Authoritative State / Events
-> Client Presentation
```

地圖資料在 Server 分成兩種不同語義：

1. `Surface.Bounds`：authoritative movement envelope。玩家 movement 仍由 `internal/navigation` 檢查 surface、blocker、portal 等資料決定是否合法。
2. `RegionCore.Polygon`：authoritative geography / region membership。polygon 可重疊，不會自動成為 collision wall 或 movement blocker。

Client 的 terrain tile、256m chunk grid、render padding、transition belt、mesh 高度與 asset path 不屬於 Server gameplay truth，沒有同步進 Server。

## 第一大陸 movement envelope

目前連續第一大陸 authoritative ground envelope：

- `minX = -2600`
- `maxX = 2600`
- `minZ = -900`
- `maxZ = 4100`
- 尺度：`5200m × 5000m`

`worlds/castle-sandbox/gameplay.json` 的既有 world ID 暫時保留，以避免在沒有正式 identity migration 的情況下破壞 persistence / reconnect contract；它不再代表舊的百米級 sandbox 尺度。

`Frostmere` 是 `Blackridge Highlands` 的子區，兩個 polygon 刻意重疊；`Definition.RegionsAt` 因此可能同時回傳 parent 與 child，呼叫端不得假設一個點只能屬於一個 Region。

## Emberwatch spawn

Server 已有正式 respawn policy owner path，因此 fresh/default safe spawn 沿用既有 stable spawn-point ID `field-camp`，座標同步到 World Master newcomer anchor：

- `X = 0`
- `Y = 0`
- `Z = -220`
- `Layer = 0`

沒有為 Client anchor 另建第二套 spawn truth。

## 未納入目前 connected movement envelope

Client World Master 中約 `(600, 5200)` 的 far-north island 是分離且後續解鎖的區域，不屬於目前 26 km² 第一大陸 connected envelope，因此本輪沒有擴大 ground surface 去包住它。

同理，Emberwatch 的 `X=-600..1000 / Z=-745..505` 是 Client terrain production coverage，不是 Server 的 RegionCore polygon，也不是整張第一大陸的 movement boundary。
